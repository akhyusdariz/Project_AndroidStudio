RANGKAIAN SERIES
1. Rangkaian Series: Sumber Tegangan + Resistor
$V_s = 10V$ $R = 2k\Omega$
(1) Hukum Ohm: $$V = I \cdot R \quad \Rightarrow \quad I = \frac{V}{R} = \frac{10V}{2k\Omega} = \boxed{5 \text{ mA}}$$ (2) Tegangan Resistor: $$V_R = I \cdot R = 5\text{mA} \times 2k\Omega = \boxed{10V}$$
2. Rangkaian Series: Sumber Tegangan + Kapasitor
$V_s = 10V$ $C = 10\mu F$
(1) Muatan Kapasitor: $$Q = C \cdot V = 10\mu F \times 10V = \boxed{100 \mu C}$$ (2) Tegangan Kapasitor (DC steady-state = open circuit): $$V_C = V_s = \boxed{10V}$$
3. Rangkaian Series: Sumber Tegangan + Induktor
$V_s = 10V$ $L = 5mH$
(1) Hubungan Induktor (DC steady-state = short circuit): $$V_L = L\frac{dI}{dt} \quad \Rightarrow \quad \text{Dalam keadaan mantap: } V_L = \boxed{0V}$$ (2) Arus melalui rangkaian: $$I = \frac{V_s}{R_{internal}} \quad (\text{tergantung resistansi internal sumber})$$
4. Rangkaian Series: Sumber Arus + Resistor
$I_s = 5\text{ mA}$ $R = 2k\Omega$
(1) Arus dalam rangkaian series: $$I = I_s = \boxed{5 \text{ mA}}$$ (2) Tegangan pada Resistor (Hukum Ohm): $$V_R = I \cdot R = 5\text{mA} \times 2k\Omega = \boxed{10V}$$
5. Rangkaian Series: Sumber Arus + Kapasitor
$I_s = 5\text{ mA}$ $C = 10\mu F$
(1) Hubungan arus-kapasitor: $$I = C\frac{dV_C}{dt} \quad \Rightarrow \quad V_C(t) = \frac{1}{C}\int I\, dt$$ (2) Tegangan kapasitor pada waktu $t$: $$V_C(t) = \frac{I_s \cdot t}{C} = \frac{5\text{mA} \times t}{10\mu F} = \boxed{500t \text{ V/s} \cdot t}$$
6. Rangkaian Series: Sumber Arus + Induktor
$I_s = 5\text{ mA}$ $L = 5mH$
(1) Hubungan arus-induktor: $$V_L = L\frac{dI}{dt}$$ (2) Dalam keadaan mantap (DC), arus konstan: $$\frac{dI}{dt} = 0 \quad \Rightarrow \quad V_L = \boxed{0V}$$
7. Rangkaian Series: Sumber Tegangan + 2 Resistor
$V_s = 10V$ $R_1 = 1k\Omega$ $R_2 = 2k\Omega$
(1) Hambatan pengganti (series): $$R_{total} = R_1 + R_2 = 1k\Omega + 2k\Omega = \boxed{3k\Omega}$$ (2) Arus rangkaian: $$I = \frac{V_s}{R_{total}} = \frac{10V}{3k\Omega} = \boxed{3.33 \text{ mA}}$$ (3) Tegangan masing-masing resistor: $$V_{R_1} = I \cdot R_1 = 3.33\text{mA} \times 1k\Omega = \boxed{3.33V}$$ $$V_{R_2} = I \cdot R_2 = 3.33\text{mA} \times 2k\Omega = \boxed{6.67V}$$
8. Rangkaian Series: Sumber Tegangan + Resistor + Kapasitor (RC)
$V_s = 10V$ $R = 2k\Omega$ $C = 10\mu F$
(1) KVL (Kirchhoff's Voltage Law): $$V_s = V_R + V_C$$ (2) DC steady-state (kapasitor = open circuit): $$V_C = V_s = \boxed{10V}, \quad V_R = \boxed{0V}, \quad I = \boxed{0 \text{ A}}$$ (3) Muatan kapasitor: $$Q = C \cdot V_C = 10\mu F \times 10V = \boxed{100 \mu C}$$
9. Rangkaian Series: Sumber Tegangan + Resistor + Induktor (RL)
$V_s = 10V$ $R = 2k\Omega$ $L = 5mH$
(1) DC steady-state (induktor = short circuit): $$V_L = 0V, \quad I = \frac{V_s}{R} = \frac{10V}{2k\Omega} = \boxed{5 \text{ mA}}$$ (2) Tegangan pada resistor: $$V_R = I \cdot R = 5\text{mA} \times 2k\Omega = \boxed{10V}$$ (3) Energi tersimpan dalam induktor: $$W_L = \frac{1}{2}LI^2 = \frac{1}{2}(5\text{mH})(5\text{mA})^2 = \boxed{62.5 \text{ nJ}}$$
10. Rangkaian Series: Sumber Arus + Resistor + Kapasitor
$I_s = 5\text{ mA}$ $R = 2k\Omega$ $C = 10\mu F$
(1) Tegangan pada resistor: $$V_R = I_s \cdot R = 5\text{mA} \times 2k\Omega = \boxed{10V}$$ (2) Tegangan pada kapasitor: $$V_C(t) = \frac{I_s}{C} \cdot t = \frac{5\text{mA}}{10\mu F} \cdot t = \boxed{500t \text{ V}}$$ (3) Muatan kapasitor pada waktu $t$: $$Q(t) = C \cdot V_C(t) = I_s \cdot t = \boxed{5t \text{ mC}}$$
11. Rangkaian Series: Sumber Arus + Resistor + Induktor
$I_s = 5\text{ mA}$ $R = 2k\Omega$ $L = 5mH$
(1) Tegangan pada resistor: $$V_R = I_s \cdot R = 5\text{mA} \times 2k\Omega = \boxed{10V}$$ (2) Tegangan pada induktor (DC mantap): $$V_L = L\frac{dI}{dt} = 0V \quad \Rightarrow \quad \boxed{V_L = 0V}$$ (3) Energi dalam induktor: $$W_L = \frac{1}{2}LI_s^2 = \frac{1}{2}(5\text{mH})(5\text{mA})^2 = \boxed{62.5 \text{ nJ}}$$
RANGKAIAN PARALEL
12. Rangkaian Paralel: 2 Sumber Tegangan + Resistor
$V_1 = 10V$, $R_1 = 1k\Omega$ $V_2 = 20V$, $R_2 = 2k\Omega$
(1) Tegangan nodal (KCL): $$V_{node} = \frac{\frac{V_1}{R_1} + \frac{V_2}{R_2}}{\frac{1}{R_1} + \frac{1}{R_2}} = \frac{\frac{10}{1} + \frac{20}{2}}{\frac{1}{1} + \frac{1}{2}} = \frac{20}{1.5} = \boxed{13.33V}$$ (2) Arus masing-masing cabang: $$I_1 = \frac{V_{node} - V_1}{R_1} = \frac{13.33 - 10}{1k\Omega} = \boxed{3.33 \text{ mA}}$$ $$I_2 = \frac{V_{node} - V_2}{R_2} = \frac{13.33 - 20}{2k\Omega} = \boxed{-3.33 \text{ mA}}$$ (3) Arus total: $$I_{total} = I_1 + I_2 = \boxed{0 \text{ mA}}$$
13. Rangkaian Paralel: 2 Sumber Tegangan + Kapasitor
$V_1 = 10V$, $R_1 = 1k\Omega$ $V_2 = 20V$, $C = 10\mu F$
(1) DC steady-state (kapasitor = open circuit): $$I_C = 0 \text{ A}$$ (2) Arus hanya mengalir pada cabang $R_1$: $$I_1 = \frac{V_1 - V_C}{R_1} \quad \text{(KCL: } I_1 = I_C = 0\text{)}$$ (3) Tegangan kapasitor: $$V_C = V_2 = \boxed{20V}$$ $$I_1 = \frac{V_1 - V_C}{R_1} = \frac{10 - 20}{1k\Omega} = \boxed{-10 \text{ mA}}$$
14. Rangkaian Paralel: 2 Sumber Tegangan + Induktor
$V_1 = 10V$, $R_1 = 1k\Omega$ $V_2 = 20V$, $R_2 = 2k\Omega$
(1) DC steady-state (induktor = short circuit): $$V_L = 0V \quad \text{(hubungkan langsung node atas)}$$ (2) Tegangan nodal = 0 (short circuit): $$I_1 = \frac{V_1}{R_1} = \frac{10V}{1k\Omega} = \boxed{10 \text{ mA}}, \quad I_2 = \frac{V_2}{R_2} = \frac{20V}{2k\Omega} = \boxed{10 \text{ mA}}$$ (3) Arus induktor (KCL): $$I_L = I_1 + I_2 = 10\text{mA} + 10\text{mA} = \boxed{20 \text{ mA}}$$
15. Rangkaian Paralel: 2 Sumber Arus + Resistor
$I_1 = 5\text{ mA}$ $I_2 = 10\text{ mA}$ $R = 2k\Omega$
(1) Arus total (KCL): $$I_{total} = I_1 + I_2 = 5\text{mA} + 10\text{mA} = \boxed{15 \text{ mA}}$$ (2) Tegangan pada resistor: $$V_R = I_{total} \cdot R = 15\text{mA} \times 2k\Omega = \boxed{30V}$$
16. Rangkaian Paralel: Sumber Arus + Kapasitor
$I_1 = 5\text{ mA}$ $I_2 = 2.5\text{ mA}$ $C = 10\mu F$
(1) Arus total masuk ke kapasitor (KCL): $$I_C = I_1 + I_2 = 5\text{mA} + 2.5\text{mA} = \boxed{7.5 \text{ mA}}$$ (2) Tegangan kapasitor terhadap waktu: $$V_C(t) = \frac{1}{C}\int_0^t I_C\, d\tau = \frac{I_C \cdot t}{C} = \frac{7.5\text{mA}}{10\mu F} \cdot t = \boxed{750t \text{ V}}$$
17. Rangkaian Paralel: 2 Sumber Arus + Induktor
$I_1 = 3\text{ mA}$ $I_2 = 6\text{ mA}$ $L = 5mH$
(1) Arus total masuk ke induktor (KCL): $$I_L = I_1 + I_2 = 3\text{mA} + 6\text{mA} = \boxed{9 \text{ mA}}$$ (2) Tegangan induktor (DC mantap = 0): $$V_L = L\frac{dI_L}{dt} = 0V \quad (\text{arus konstan})$$ (3) Energi tersimpan: $$W_L = \frac{1}{2}LI_L^2 = \frac{1}{2}(5\text{mH})(9\text{mA})^2 = \boxed{202.5 \text{ nJ}}$$
18. Rangkaian Paralel: 2 Sumber Tegangan + 2 Resistor
$V_1 = 10V$, $R_1 = 1k\Omega$ $V_2 = 20V$, $R_2 = 2k\Omega$
(1) Tegangan nodal (KCL di node atas): $$\frac{V_n - V_1}{R_1} + \frac{V_n - V_2}{R_2} = 0$$ $$V_n = \frac{\frac{V_1}{R_1} + \frac{V_2}{R_2}}{\frac{1}{R_1} + \frac{1}{R_2}} = \frac{10 + 10}{1.5} = \boxed{13.33V}$$ (2) Arus masing-masing cabang: $$I_1 = \frac{V_n - V_1}{R_1} = \frac{13.33 - 10}{1k\Omega} = \boxed{3.33 \text{ mA}}$$ $$I_2 = \frac{V_n - V_2}{R_2} = \frac{13.33 - 20}{2k\Omega} = \boxed{-3.33 \text{ mA}}$$
19. Rangkaian Paralel: 2 Sumber Tegangan + Resistor + Kapasitor
$V_1 = 10V$, $R_1 = 1k\Omega$ $V_2 = 20V$, $R_2 = 2k\Omega$
(1) DC steady-state (kapasitor = open circuit, $I_C = 0$): $$\frac{V_n - V_1}{R_1} + \frac{V_n - V_2}{R_2} = 0$$ $$V_n = \frac{10 + 10}{1.5} = \boxed{13.33V} = V_C$$ (2) Arus melalui masing-masing cabang: $$I_1 = \frac{V_n - V_1}{R_1} = \boxed{3.33 \text{ mA}}, \quad I_2 = \frac{V_n - V_2}{R_2} = \boxed{-3.33 \text{ mA}}$$
20. Rangkaian Paralel: 2 Sumber Tegangan + Resistor + Induktor
$V_1 = 10V$, $R_1 = 1k\Omega$ $V_2 = 20V$, $R_2 = 2k\Omega$
(1) DC steady-state (induktor = short circuit, $V_L = 0$): $$V_n = 0V \quad (\text{node atas shorted ke ground melalui } L)$$ (2) Arus dari masing-masing sumber: $$I_1 = \frac{V_1 - V_n}{R_1} = \frac{10V}{1k\Omega} = \boxed{10 \text{ mA}}$$ $$I_2 = \frac{V_2 - V_n}{R_2} = \frac{20V}{2k\Omega} = \boxed{10 \text{ mA}}$$ (3) Arus induktor (KCL): $$I_L = I_1 + I_2 = 10\text{mA} + 10\text{mA} = \boxed{20 \text{ mA}}$$
21. Rangkaian Paralel: 2 Sumber Arus + Resistor + Kapasitor
$I_1 = 5\text{ mA}$ $I_2 = 3\text{ mA}$ $R = 2k\Omega$
(1) KCL di node atas (arus total masuk): $$I_{total} = I_1 + I_2 = 5\text{mA} + 3\text{mA} = \boxed{8 \text{ mA}}$$ (2) Arus terbagi antara $R$ dan $C$: $$I_R + I_C = I_{total} = 8\text{ mA}$$ (3) Tegangan pada resistor: $$V_R = I_R \cdot R \quad \text{(tergantung distribusi arus)}$$
22. Rangkaian Paralel: 2 Sumber Arus + Resistor + Induktor
$I_1 = 5\text{ mA}$ $I_2 = 3\text{ mA}$ $R = 2k\Omega$
(1) KCL di node atas: $$I_L + I_R = I_1 + I_2 = 5\text{mA} + 3\text{mA} = 8\text{ mA}$$ (2) DC steady-state (induktor = short circuit, $V_L = 0$): $$V_{node} = I_R \cdot R \quad \text{(semua arus } I_L \text{ melewati short)}$$ (3) Arus induktor (mengambil semua arus karena short): $$I_L = I_1 + I_2 - I_R = 8\text{mA} - I_R$$ $$\text{Dengan } I_R = \frac{V_{node}}{R} = 0 \Rightarrow I_L = \boxed{8 \text{ mA}}$$
RANGKAIAN KOMPLEKS (RLC & Multi-Sumber)
K1. Rangkaian Paralel RLC - 3 Sumber
$V_s = 10V$ $R = 2k\Omega$ $C = 10\mu F$ $L = 5mH$
(1) DC steady-state分析: $$\text{Kapasitor } C \text{ = open circuit } (I_C = 0)$$ $$\text{Induktor } L \text{ = short circuit } (V_L = 0)$$ (2) Tegangan node (terhubung ke ground melalui $L$): $$V_{node} = 0V$$ (3) Arus dari sumber: $$I_R = \frac{V_s - V_{node}}{R} = \frac{10V}{2k\Omega} = \boxed{5 \text{ mA}}$$ $$I_C = 0 \text{ A}, \quad I_L = I_R = \boxed{5 \text{ mA}}$$ $$\therefore \quad I_{total} = I_R + I_C = 5\text{mA} + 0 = \boxed{5 \text{ mA}}$$
K2. Rangkaian Paralel: 2 Sumber Tegangan + 2 Resistor
$V_1 = 15V$, $R_1 = 2k\Omega$ $V_2 = 10V$, $R_2 = 3k\Omega$
(1) Tegangan nodal (KCL di node atas): $$\frac{V_n - V_1}{R_1} + \frac{V_n - V_2}{R_2} = 0$$ $$V_n = \frac{V_1 \cdot R_2 + V_2 \cdot R_1}{R_1 + R_2} = \frac{15 \times 3 + 10 \times 2}{2 + 3} = \frac{65}{5} = \boxed{13V}$$ (2) Arus masing-masing cabang: $$I_1 = \frac{V_n - V_1}{R_1} = \frac{13 - 15}{2k\Omega} = \boxed{-1 \text{ mA}}$$ $$I_2 = \frac{V_n - V_2}{R_2} = \frac{13 - 10}{3k\Omega} = \boxed{1 \text{ mA}}$$ (3) Arus total: $$I_{total} = I_1 + I_2 = -1\text{mA} + 1\text{mA} = \boxed{0 \text{ mA}}$$
